## 복구 경로

| 대상 | 판단 근거 | 결정 및 결과 |
|---|---|---|
| 초기 데이터 보존 | 부팅 불능 상태에서 필요한 자료 존재 | SSD 전체 이미지 확보 후 복구 진행 |
| GPT 복원 | 백업 GPT와 장애 당일 정상 파티션 기록 일치 | 실제 SSD에 복원, 파티션 인식 회복 |
| 레지스트리 후보 | 사본 로드는 성공했으나 시퀀스 간격 존재, 부팅 검증 없음 | SSD 미적용, 검사 결과만 보존 |
| Windows 재설치 | GPT·NTFS 수리 후에도 0x74 지속, 오프라인 시스템 검사 중단 | 자료 보존 후 새 설치 결정 |
| 설치 미디어 | ASUS 복구 USB의 Wi-Fi 연결 중 충돌 | Microsoft 공식 USB로 전환, 설치 완료 |

## 드라이버·펌웨어 적용

| 항목 | 판단 근거 | 조치 |
|---|---|---|
| NVIDIA | 616.92 실제 적용 및 공식 WHQL 버전 확인 | 유지 |
| Armoury 제어 인터페이스 | 현재 1.2.0.2, 준비 파일 1.2.0.1 | 현재 버전 유지 |
| 카메라 확장 | 신규 패키지의 지원 장치 ID 불일치 | 미설치 |
| BIOS | 현재 310, 당시 공식 최신도 310 | 동일 버전 재설치 생략 |
| SSD 펌웨어 | 적용 가능한 공식 OEM 업데이트 미확인 | V8MA000 유지 |
| Parade HID | 누락 장치 ID와 패키지 일치 | 설치 후 문제 장치 해결 |
| Radeon | 장치 ID·서명·해시 일치 | ASUS 공식 패키지 적용 |

Radeon 설치 시 동봉 Crash Defender가 25.20.0.4에서 25.10.0.4로 변경됨. 재부팅 후 서비스 실행 및 Windows Update 재제공 없음 확인, 추가 변경 없이 유지.

## 작업 후 재확인

| 최초 관찰 | 재확인 결과 | 반영 |
|---|---|---|
| AURA 업데이트 요청 후 앱 종료 | 설치 버전은 0.0.21 유지, 이후 x86·x64 모두 0.0.60 확인 | 실제 버전 변경 시점에 완료 처리 |
| Storport 조회 결과 비어 있음 | 채널 접근 거부 확인, 관리자 조회에서 이벤트 검출 | 오류 없음 판단 정정 |
| Armoury 성능 모드 선택 | Windows 구성표는 Turbo 유지 | Armoury Windows 모드 / 균형 조정 적용 확인 |
| Windows 메모리 진단 예약 후 재부팅 | 완료 이벤트 없음, 검사 진행 여부 불확실 | 미확인으로 기록 |

## 점검 종료 범위

- 시스템·SSD·MyASUS 검사 완료. 확인된 범위에서 부품 고장 미검출.
- 추가 부하 검사 없이 일상 사용 재개 결정.
- 오프라인 메모리 검사, 일부 주변기기 기능, 절전 복귀는 미완료로 유지.
