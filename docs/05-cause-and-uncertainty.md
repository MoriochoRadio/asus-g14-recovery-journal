# 원인 분석

[처음으로](../README.md) · [검사 결과](04-validation.md)

**부팅을 방해한 손상은 확인됐으나, 최초 손상 원인은 미확정.** 재설치로 사용 환경은 회복됐으며, 현재 검사에서 부품 고장은 검출되지 않음.

## 확인된 문제

| 항목 | 확인 내용 | 복구·검사 결과 |
|---|---|---|
| 파티션 구조 | 주 GPT·보호 MBR 손상 | 백업 GPT 복원 후 파티션 인식 회복 |
| 파일시스템 | NTFS 구조 오류 | 수리 후 파일 접근 회복 |
| 기존 Windows | BAD_SYSTEM_CONFIG_INFO(0x74) | 기존 환경의 정상 부팅 복구 실패 |
| 오프라인 시스템 검사 | DISM의 SAM 하이브 로드 실패 | 검사 초기화 단계에서 중단 |
| ASUS 복구 USB | Wi-Fi 연결 중 0xD1/nwifi.sys | 해당 복구 경로 중단, Microsoft USB로 전환 |

손상 발생 순서와 최초 충돌 사이의 인과관계는 확인되지 않음. ASUS 복구 USB의 오류는 기존 Windows의 0x74와 별도이며, 새 Windows에서 재발한 기록이 아님. [E01–E03, E07, E08]

## SSD 관련 근거

| 구분 | 관측 |
|---|---|
| 전체 이미지 읽기 | rescued 100%, read errors 0 |
| SMART 및 자체 검사 | 매체 오류 0, 짧은 자체 검사 통과 |
| 과거 NVMe 관리 명령 이벤트 | 2025년부터 존재. 보존 로그에서 오류 811건·시간초과 823건, 합계 1,634건 |
| 새 Windows 재부팅 직후 | 관리 명령 오류 1건·시간초과 1건 |
| 당시 데이터 I/O 집계 | 실패 카운터 0 |

새 설치 뒤에도 관리 명령 이벤트가 남아 있어 SSD·컨트롤러·펌웨어·드라이버 동작과 관련한 단서로 기록. 다만 데이터 손상이나 최초 장애의 원인으로 연결할 증거는 확보되지 않음. SMART·짧은 검사 결과만으로 간헐적 하드웨어 문제까지 배제할 수는 없음. [E02, E10–E12]

## 연결이 확인되지 않은 이력

| 이력 | 확인된 범위 | 미확정 사항 |
|---|---|---|
| 디스크 앞쪽 영역 변화 | 장애 당일 아침 정상 파티션 로그 존재, 이후 이미지 앞쪽 1MiB는 거의 0 | 변경 시각·주체·경로, 최초 충돌 전후 여부 |
| 장애 당시 프로그램 사용 | 보존된 PowerShell 기본 로그의 제한된 검색에서 파괴적 디스크 명령 미발견 | 모든 실행 경로는 조사되지 않음. Operational 로그 하나는 손상으로 읽기 실패 |
| 9월 초 Hello/PIN 문제 | 이후 컨테이너 읽기 성공 기록 확인 | 인증 문제와 디스크 손상의 공통 원인 여부 |
| ASUS USB Wi-Fi 충돌 | 복구 환경에서 nwifi.sys 오류 확인 | 덤프·호출 스택 미확보로 무선랜 칩 또는 특정 드라이버 결함 판단 불가 |

참고: E02–E04, E08.

## 조사 범위

| 자료 | 범위 |
|---|---|
| 보존 진단 파일 | 693개: EVTX 263개, WER 383개, DMP 13개 등 |
| System 로그 | 이벤트 38,916개 확인 |
| 선택한 38개 로그 | 이벤트 56,564개 추출 |
| WER | 발생 시각·ID 대조 후 378개 보고로 구분 |
| 덤프 | 이전 날짜 기록과 중복 포함. 모든 덤프의 WinDbg 정밀 분석은 미실시 |

최초 장애 당일의 새 커널 덤프는 확인되지 않음. 이후 보고된 GPU 오류 중 실제 발생일이 이전 달인 기록은 별도로 구분. [E02, E03]

## 판단 정정

| 최초 결과 | 재확인 후 판단 |
|---|---|
| 정상 PC의 레지스트리 로드 실패 | 대조군도 실패. 노트북 WinRE 사본 검사에서는 성공 |
| 빈 Storport 조회 결과 | 권한 부족. 관리자 조회에서 오류 확인 |
| 메모리 검사 완료로 추정 | 완료 이벤트와 확실한 사용자 확인이 없어 미확인 처리 |

최종 조치: 새 Windows와 드라이버로 사용 환경 복구. 미확정 원인과 남은 검사는 기록하고, 추가 부하 검사 없이 일상 사용 재개.
