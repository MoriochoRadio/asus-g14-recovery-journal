## 9월 18–19일 — 기존 Windows 복구 시도

1. BIOS는 SSD를 인식했지만 Windows 부팅 항목·설치 환경의 파티션 인식에 문제가 있었다.
2. 이미지의 주 GPT/보호 MBR 손상과 정상 백업 GPT를 확인했다.
3. 과거 정상 파티션 로그와 대조한 뒤 실제 SSD의 GPT를 복원했다. 파티션 인식이 회복됐다.
4. NTFS 구조 오류를 수리했다. 파일 목록을 읽을 수 있게 됐으나 Windows는 부팅하지 못했다.
5. 자동 재시작을 멈춘 화면에서 기존 Windows의 BAD_SYSTEM_CONFIG_INFO(0x74)를 확인했다.
6. SYSTEM/SOFTWARE 및 로그를 별도 사본으로 분석하고 복구 후보를 만들었다.
7. 9월 19일 13:26:22의 WinRE 검사에서 대조군·원본+로그 사본·후보 SYSTEM·SOFTWARE 로드/조회가 성공했다. 후보를 SSD에 덮어쓰지는 않았다.
8. 오프라인 SFC는 수행 불가로 중단됐고, 13:44:24 DISM 로그는 SAM 하이브 로드 실패를 기록했다.
9. 데이터를 보존한 상태에서 새 설치를 선택했다.

참고: E01, E03, E05, E06, E07.
